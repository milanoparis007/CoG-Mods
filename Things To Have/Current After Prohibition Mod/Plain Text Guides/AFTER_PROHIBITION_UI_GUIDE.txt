AFTER PROHIBITION UI GUIDE
==========================

AfterProhibitionUI is a separate BepInEx plugin for UI-only fixes and visual ownership.

Install location:

BepInEx\plugins\AfterProhibitionUI.dll

Current purpose:

- Keep popup docking and dialog visual placement separate from GameplayTweaks.
- Own generic menu and popup retheme work delegated by GameplayTweaks.
- Own crew inspect footer button rendering.
- Own stale portrait clearing and blank connection-card render suppression.
- Own crew sidebar jail-bar visuals.
- Own crew-management jail status text visuals.
- Report compatibility state for PIA UI Enhancer, CoGCustomAssets, CustomPortraits, safebox UI, and menu/sidebar overlap.

What this plugin does not own:

- Economy stock, shop buy/sell, banks, warehouses, or inventory rules.
- Delivery routes, route continuation, vehicle movement authority, or command execution.
- Family, spouse, relationship generation, or relation sorting.
- Political quests, AI hiring, combat, retaliation, territory, or gang simulation.
- Jailed crew assignment blocking or command safety. GameplayTweaks still owns those rules.

Runtime config:

The config file is generated by BepInEx under its config folder after the game starts.

Feature switches:

Features.EnableTextSanitizer
Features.EnableCrewSidebarJailBars
Features.EnablePopupDocking
Features.EnableMenuRethemeBridge
Features.EnableCrewInfoButtons
Features.EnableStalePortraitGuards
Features.EnableCrewManagementJailVisuals

Expected live log lines:

[Info   :After Prohibition UI] Jail crew sidebar jail-bars patch applied
[Info   :After Prohibition UI] PopupDocking patch applied basePopup=True hudDialog=False
[Info   :After Prohibition UI] CrewInfoButtons inspect patch methods=2
[Info   :After Prohibition UI] ConnectionsTab render guard patched=4
[Info   :After Prohibition UI] StalePortraitGuards patched=15 owner=AfterProhibitionUI
[Info   :After Prohibition UI] CrewManagementJailVisuals patched=2 owner=AfterProhibitionUI

Expected GameplayTweaks skip lines when both DLLs match:

[VERIFY-HOTFIX] [CrewInfoButtons] skipped in GameplayTweaks owner=AfterProhibitionUI
[VERIFY-HOTFIX] [Jail] crew sidebar jail-bars skipped in GameplayTweaks owner=AfterProhibitionUI
[VERIFY-HOTFIX] [ConnectionsTab] skipped in GameplayTweaks owner=AfterProhibitionUI
[GameplayTweaks] Multi-crew vehicle: crew management jail text visuals skipped; owner=AfterProhibitionUI

Quick live test checklist:

1. Main menu and game load without UI exceptions.
2. Crew side panel stays in its normal side position.
3. Modal popups stay inside their parent viewport.
4. Crew inspect popup shows the extra footer buttons once, not duplicated.
5. Connections tab does not show blank Name cards or stale blank portraits.
6. Crew picks do not keep old portraits/text after selection, vehicle switch, or route refresh.
7. Person info, conversation, crew inspect, and portrait popups do not flash a previous person's portrait.
8. Jailed crew show jail status text in crew management UI.
9. Jailed crew still cannot be assigned through GameplayTweaks command safety.
10. Logs show AfterProhibitionUI ownership and matching GameplayTweaks skip lines.

Troubleshooting:

- If duplicate crew inspect buttons appear, confirm the live GameplayTweaks.dll matches the staged package and logs the CrewInfoButtons skip line.
- If old connections-tab null-finalizer lines appear from GameplayTweaks, confirm the live GameplayTweaks.dll matches the staged package and logs the ConnectionsTab skip line.
- If jail text visual ownership still logs from GameplayTweaks, update both AfterProhibitionUI.dll and GameplayTweaks.dll together.
- If an external UI DLL changes button or popup templates, disable the specific AfterProhibitionUI feature switch first instead of removing the whole plugin.
