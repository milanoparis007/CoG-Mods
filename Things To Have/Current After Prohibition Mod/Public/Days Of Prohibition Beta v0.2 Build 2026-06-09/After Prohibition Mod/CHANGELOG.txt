# Current After Prohibition Mod Changelog

## 2026-06-09 Beta v0.2 Build

This beta build keeps the separate public beta line moving without overwriting the older public releases.

- Tightened dirty-cash route handling so command flushes do not clear the wrong vehicle or business state too early.
- Added a civic nonpurchase fallback so school and similar civic content can still appear when custom data is missing or partial.
- Kept the route and front-pressure work aimed at reliable movement, closures, and important-business pressure.
- Added crew relations coverage for pacts, grapevine, spouse search, family growth, loyalty, and witness/state-case tracking.
- Added murder witness pressure so a crew member can build toward a state case instead of every witness acting like one immediate case.
- Kept the player-facing witness flow around search, threaten, silence, and case reset behavior in the current beta line.
- Kept the current split-DLL package structure so gameplay, UI, economy, family, politics, routes, and compatibility stay easier to debug.
- Updated the public beta package with the current plugin DLLs and matching `CoG_Data` content.
- Included the latest CopKilling beta package changes alongside the GameplayTweaks update.

## 2026-06-08 Beta v0.1 Build

- Enemy robberies now start from a meeting route instead of feeling like an instant background event.
- Robbery prompts now clean up better when closed, interrupted, or when the player moves too far away.
- Front closures should be more reliable, with enemies getting more time to reach the target before changing plans.
- Non-boss enemy crew and multiple vehicles can now take part in front and business pressure more often.
- Important businesses can now be targeted through war pressure, not only robbery outcomes.
- Defended fronts, retaliation, truce checks, and combat timing were cleaned up so attacks happen at more believable moments.

## 2026-06-05 Public Robbery And Log Cleanup Release

- Added AI-human robbery and extortion pressure for exposed, weak, or locally pressured human crews.
- Robbery prompts now resolve at the start of the next human turn.
- Added the boss crew relations robbery response toggle for prompt or auto-evade behavior.
- Refusal and evasion outcomes can now lead to payment, pressure, or rare attack warnings.
- Important-business closures now target valid visible shops and block buy/sell interactions.
- Default logs now suppress routine spam while keeping compact first-report breadcrumbs.
