Reflection Pattern

Type api = Type.GetType("AfterProhibitionAssets.AssetRegistry, AfterProhibitionAssets");

Use reflection to call TryGetSprite or TryGetTexture from other plugins. Missing keys return false and should fall back to vanilla behavior.

Current Active Consumer

main-menu.primary, main-menu.alt1, and main-menu.alt2 are consumed by AfterProhibitionAssets itself for optional main menu background rotation.

Prepared Future Consumers

loading.primary can be used by a future loading-screen patch.
icon.* keys can be used by future UI icon patches.
portrait.* keys can be used by future portrait replacement patches.

Stability Rule

Consumer plugins should not assume AfterProhibitionAssets is installed. Check whether the reflection type exists before calling the API.
