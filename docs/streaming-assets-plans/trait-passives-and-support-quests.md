# Trait Passives And Support Quests

## Goal

Capture the trait-based passive-income and support systems requested so they can be built mostly through content and quest chains.

## Scope

1. Small gang start at schools that gives `$4` passive income, requires local goons, and unlocks recruiting muscle there.
2. Religious characters can support churches weekly for `-1`, which opens the support path and loan access.

## Streaming Assets First

Start with quest and interaction content:

- school interaction chain
- church support chain
- passive-income unlock items or statuses
- trait requirements
- local-goon requirements
- recruit-muscle unlock states
- weekly support or recurring quest content where the data layer allows it

## Patch Only If Needed

Use code only if the passive weekly payments or recurring support loop cannot be represented through existing timing / quest systems.

Likely fallback cases:

- weekly automatic tick handling
- passive-income accumulation outside normal quest cadence
- unlocking repeatable recruit-muscle behavior from a school node

## Task Breakdown

1. Build the school-based small-gang entry chain.
2. Require local goons before the passive opens.
3. Add the `$4` passive-income effect.
4. Unlock muscle recruitment at the school after completion.
5. Build the weekly church-support action for `religious`.
6. Charge `-1` weekly support cost.
7. Tie successful church support into the loan option.

## Desired Outcome

Traits should matter in a grounded way:

- connected and smart traits open paperwork / schemes
- religious traits create community-finance leverage
- early crew-building can come from schools instead of only from the normal hire loop
